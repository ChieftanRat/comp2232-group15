MechanicHourlyRate

Determines the hourly rate of a mechanic based on their experience level.

Services
Name Description
getHourlyRate Returns 20 for novice, 60 for intermediate, and 100 for expert mechanics.
calculateLabourCost Calculates the total labour cost by multiplying the hourly rate by 8 hours and the number of repair days.

MechanicRepairTime

Determines the minimum repair time based on the mechanic's experience level.

Services
Name Description
getMinimumRepairTime Returns 20 days for novice, 15 days for intermediate, and 10 days for expert mechanics.
calculateRepairTime Determines the repair time by selecting the greater of the mechanic's minimum repair time and the vehicle's minimum repair time.

MechanicAssignment

Searches mechanics in their listed order and assigns the first available mechanic to a vehicle.

Uses
Name Relationship Description
Mechanic 1 to * label searches Searches the list of mechanics to locate the first available mechanic.

Services
Name Description
findAvailableMechanic Searches the mechanics in their listed order and returns the first available mechanic.
assignMechanic Assigns the selected mechanic to the vehicle and marks the mechanic as unavailable.
releaseMechanic Marks the mechanic as available when the assigned vehicle has been repaired.

VehicleWaitingList

Maintains a waiting list of vehicles that cannot be repaired immediately because all mechanics are busy.

Uses
Name Relationship Description
Vehicle 0 to * label contains Contains vehicles waiting for an available mechanic.

Services
Name Description
addVehicle Adds a vehicle to the waiting list when no mechanic is available.
removeVehicle Removes the first vehicle from the waiting list when a mechanic becomes available.
hasWaitingVehicles Checks whether there are any vehicles in the waiting list.
getWaitingCount Returns the number of vehicles currently waiting for repair.
assignWaitingVehicle Assigns the first waiting vehicle to a mechanic who has completed a repair.
